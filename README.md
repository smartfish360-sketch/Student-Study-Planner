# Student Study Planner

A simple web app that helps a student keep track of study tasks and assignments.

## Features
- Add a task with a title and subject/course name
- View tasks in a list, with priority labels
- Mark tasks complete or incomplete
- Delete tasks
- Tasks are saved in the browser (local storage) and stay after a refresh
- Empty-state message, and blank titles are rejected
- Filter by All, Pending or Completed

## Built with
HTML, CSS and JavaScript
